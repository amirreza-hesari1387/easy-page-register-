# Easy Page Register

A simple and clean registration page built with **HTML5** and **CSS3**.

This project is a front-end practice project focused on creating a registration form, styling input fields, and working with basic responsive layouts.

## ✨ Features

- Clean and simple registration form
- First name and last name fields
- Email and password fields
- Terms and conditions checkbox
- Custom button hover and focus effects
- Custom font using `@font-face`
- Basic responsive styling with CSS media queries

## 🛠️ Built With

- HTML5
- CSS3
